# ranadhir19.github.io

Master landing page — Ranadhir Ghosh's AI Knowledge Hub.

Live at **https://ranadhir19.github.io/** (GitHub Pages, served from `main`).

## Purpose

A single front door for the open-source libraries, with the mission of giving back
to the community whose shared knowledge built the author's understanding:

- [agentic-systems-lab](https://github.com/ranadhir19/agentic-systems-lab) — six agentic-AI systems as a pip library
- [llm-inference-engine](https://github.com/ranadhir19/llm-inference-engine) — advanced LLM inference from first principles
- [research](https://github.com/ranadhir19/research) — runnable companions to research papers

The page explains each repository and offers guided learning paths ("I want to build agents",
"I want to understand inference", "I want research I can run").
