Where should you start?

Three guided paths depending on your goal. Every project page follows the same shape — Problem, Gap, Solution, Architecture, Results, Insights, Implementation — so you always know where you are.

🤖 I want to build AI agents

  1. agentic-systems-lab → user guide: install the package, run the 5-minute quickstarts.
  2. meridian: how multi-agent orchestration and learned routing work.
  3. healflow: making agent workflows reliable in production.
  4. sentinel: auditability and tamper-evidence for agent actions.

⚙️ I want to understand LLM inference

  1. llm-inference-engine → nano-transformer: a decoder, built from scratch in numpy.
  2. paged-kv + roofline: where the memory actually goes.
  3. spec-decode + disagg-serve: how production serving gets fast.
  4. quant-lab + sched-lab: the cost/latency levers that matter.

📄 I want research I can run

  1. research → pick a paper: each page cites its paper.
  2. Run the example: the paper's core idea as working code.
  3. Read Results vs Insights: what the experiments actually showed.
